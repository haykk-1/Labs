**4. using in, out, ref, params, and parameters by default values,**

## Խնդրի դրվածքը

* Ստեղծել static A(), B(), C() մեթոդները, համապատասխանաբար in, out, ref, մոդֆիկատորները փորձարկելու համար
* Ստեղծել նաև SumValues(parasm … ) մեթոդը որը կգումարի մուտքում եկած ամբողջ թվերը, թվերի քանակը ֆիքսված չէ
* ցույց տալ թե ինչպես են աշխատում այս մեթոդները, Main() մեթոդում

## Կատարած առաջադրանքը

`Program` կլասի `A(in int)` մեթոդը կարդում է թիվը և օգտագործում լռելյայն `multiplier = 2` պարամետրը։ `B(out int)`-ը արժեք է տալիս նոր փոփոխականին։ `C(ref int)`-ը փոխում է արդեն գոյություն ունեցող փոփոխականը, իսկ `step`-ի լռելյայն արժեքը 1 է։ `SumValues(params int[])`-ը `for` ցիկլով գումարում է փոխանցված բոլոր թվերը։ `Main()`-ում ամեն մեթոդի համար առանձին օրինակ կա։
